## 两条建议阅读路径

开发和部署：端与云服务架构 → 交互时序 → iroh 设备身份与连接 → CI 与兼容性测试 → 发布流程。

官网设计和内容：官网内容与展示方案 → 端与云服务架构中的总览图和数据边界 → 交互时序中的配对、连接和串口图。

## 阅读约定

- 时序图中的 **A** 通常是生成邀请或提供物理串口的机器，**B** 通常是导入邀请或使用串口的机器。两端运行同一套客户端，角色可以互换。
- “已实现”描述当前代码提供的行为；“已验证”只对应明确列出的测试或构建结果。
- “规划”描述后续官网、项目自建中继与地址发现的部署，不表示它们已经上线。
- Mermaid 代码块是图的可编辑源文件，可在支持 Mermaid 的仓库阅读器中查看，后续也可以导出 SVG 用于官网。
- 源码与说明冲突时，应先核对源码和测试，再同步修改文档与官网表述。

目前没有部署项目自有中继、地址发现或官网。默认客户端可使用公共 iroh 服务；本机临时中继只用于自动化测试。
