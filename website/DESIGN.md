# Linkport 官网设计

2026-11-17。官网独立于桌面工作区，遵循项目黑白灰品牌和现有双插座图形。

## 方向

用简洁的开发工具页面解释一个具体任务：把远端显式共享的串口接入本机工具。参考
Magpie 的中文粗细层级与产品优先构图、iroh 的几何西文字体与连接示意，不复用其文案或商标。

## 版式与字体

- 最大版心 1120px，顶部导航 72px；首屏用两列并排呈现用途与串口连接场景。
- 正常章节间距 54–70px；移动端 42px。移除独立的重复宣言和大字装饰页脚。
- 自托管 Space Grotesk 为西文主体，IBM Plex Mono 用于端口、命令与时间戳；中文采用
  PingFang SC / Microsoft YaHei 等系统无衬线字体。标题强化字重，正文避免密集负字距。
- 信息通过标题、短句、图示和按需展开的 FAQ 分层；正文不嵌入实现细节或制作过程说明。

## 图形与交互

- 首屏的串口设备、线缆、本机终端构成单一场景，使用与端口路径相配的精确矢量图形。
- 连接原理压缩为同一对端点和两条 Bézier 路径；切换直连/中继时同步文字、路径和辅助状态。
- 三步流程保留键盘操作、显式共享开关和未共享状态。所有演示只在浏览器内改变展示。
- 短入场、步骤过渡与流量线条为主；滚动时设备稍拉开，线缆展开。不接管滚动。
- 减少动态效果时停用入场和流动动画，保持所有内容与功能可见。

## 能力表述

下载入口指向 GitHub 原生构建流程，不伪造稳定 Release 或直接下载成功。保留开发预览、
macOS 未公证、com0com 驱动、PTY 控制线和手动重连等边界。私钥、共享权限与设备信任由本机管理；
中继内容加密与连接元数据可见是不同边界。
